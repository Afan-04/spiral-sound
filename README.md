# 🎵 Spiral Sounds

An online classic vinyl store built with Node.js, Express and SQLite.

## Features
- Browse vinyl records, filter by genre, and search by title, artist or genre
- User registration and login with bcrypt password hashing and session-based auth
- Per-user shopping cart: add items, remove items, clear the cart, live item count
- Protected cart API routes via custom auth middleware
- Responsive UI with a mobile menu, built with vanilla JavaScript (ES modules)

## Tech Stack
Node.js · Express · SQLite · express-session · bcryptjs · validator · HTML/CSS/JS

## Getting Started
npm install
npm start
# → http://localhost:8000
